Dabba Wala — Static Demo Website (Zepto-style)

How to use:
1. Unzip the package.
2. Open index.html in Chrome (recommended) to demo.
3. This demo is fully static — no server required.
4. Replace images in /images/ with real product photos (same filenames) before showing the client.

Features included:
- Categories, product grid, add-to-cart
- Checkout with address (typing), voice input (Chrome), photo upload, handwriting/draw input
- Cart persisted in localStorage
- Order placement stores in localStorage and shows a simulated tracking flow
